1. 概要と特徴

「ブロック de HTML エディタ」は、プログラミングコードを書くことなく、ブロックをドラッグ＆ドロップして配置・調整するだけで本格的なWebページやインタラクティブなミニアプリを作成できるツールです。

🧩 直感的なブロック構築

HTMLの要素（テキスト、画像、ボタン、フォームなど）をブロック単位で組み合わせられます。

🎁 かんたん入力（プリセット）

色・サイズ・URL・SVG画像などを、入力欄へワンタッチで適用できます。

⚡ ノーコード動作実装

「ボタンを押すと文字が変わる」「カウントダウンをする」などの動きをJavaScript不要で設定可能です。

📱 リアルタイム確認

PC表示・スマホ表示を切り替えながら、作成中の画面動作を即座にテストできます。

2. 画面構成

エディタ画面は大きく分けて4つのエリアで構成されています。

① 上部バー（トップ・タブ）

操作の「戻る」「やり直す」ボタン、およびブロックのカテゴリ（デザイン、メディア、フォーム等）を切り替えるタブが並んでいます。

② 左側：パレット

選択したタブに応じたパーツ（HTML要素、CSSスタイル、プリセットなど）の一覧が表示されます。ここから右側へドラッグして配置します。

③ 中央：ワークスペース

ブロックを配置して組み立てるメイン作業エリアです。要素の親子構造（枠の中にボタンを入れる等）を視覚的に管理できます。

④ 右側：プレビュー＆操作

上部で「画面の完成像（PC/スマホ）」と「生成コード」を切り替え表示。下部のボタンで保存やファイル出力を行います。

3. 基本的な使い方（作成手順）

  1. ブロックをパレットからドラッグ＆ドロップする
    画面上部のカテゴリタブ（例：📝 テキスト、🔗 リンク、🧾 フォームなど）を選択し、左側のパレットにあるブロックの左端ハンドル（⋮⋮）を掴んで、中央のワークスペース内のドロップ領域（「ここにブロックをドロップ」）へ持っていきます。
  2. プロパティを設定する
    配置したブロックのテキストボックスやドロップダウンを編集します。
    • ID: 他のブロックと連携させるための識別名（例: btn1, out1 など）。
    • テキスト / ラベル: 画面に表示される文字。
  3. 枠（コンテナ）の中にブロックを組み込む
    📦 装飾ボックスや🃏 カードなどの「枠（コンテナ）」ブロックを配置すると、その中にさらに別のブロックを入れることができます。
  4. デザイン（CSS）を付与する
    🎨 CSS タブから「幅」「背景色」「文字サイズ」「角丸」などのCSSブロックを引き出し、ブロック内の「CSSスロット」にセットすることでスタイルを変更できます。
  5. プレビューで確認する
    右側パネルで完成イメージをリアルタイム確認します。🖥（デスクトップ）と📱（モバイル）アイコンで表示幅を変更できます。

5. 「かんたん入力（プリセット）」の使い方

カラーコードやサイズの値、サンプル画像のURLなどを手入力する手間を省くための強力な補助機能です。

✨ プリセットの使い方手順
  1. 上部タブの🎁 かんたんをクリックします。
  2. パレットに「色」「長さ・サイズ」「URLサンプル」「SVG図形」などが表示されます。
  3. 使いたいプリセットブロック（オレンジ色の項目）をドラッグすると、ワークスペース内の入力可能なフィールドが黄色くハイライトされます。
  4. 目的の入力欄の上にドロップすると、その値（例：#2ec4a6 や https://picsum.photos/400/300）が自動入力されます。

6. 動的な仕組み（イベント・動作）を作る

JavaScriptの知識がなくても、クリックや入力に応じて表示が変わる「動きのあるWebページ」が作れます。

基本原理：IDによる連携

動きを作るには、「操作する側（ボタンや入力欄）」と「変化する側（テキストや出力欄）」のIDを繋ぎ合わせます。

💡 例：ボタンを押したら文字を表示する仕組み
  1. 📤 出力欄 ブロックを配置し、IDに out1 と入力。
  2. 🔘 ボタン ブロックを配置し、IDに btn1 と入力。
  3. 上部タブから🔢 動作を選び、💬 クリックでテキスト表示 ブロックをボタンの「動作スロット」にドロップ。
  4. 設定欄の「表示先ID」に out1、「表示する文字」に こんにちは！ と入力。
  5. 右側のプレビューでボタンを押すと、出力欄に文字が表示されます！

主な動作ブロックカテゴリ

  • 値の操作・計算： 入力された2つの数値を足し算・引き算する、変数に保存する、カウンター（＋/ー）。
  • 表示の切り替え： 要素を表示/非表示にする、おみくじのように「ランダムに1つ表示」する。
  • メディア・キャンバス： 動画の再生/一時停止、お絵かきキャンバスの消去・ペン色変更。
  • タイマー・API： カウントダウンタイマー、ストップウォッチ、時間が経つと自動で進む進行バー。

7. 保存・読み込み・出力（アクション機能）

画面右下の「アクションエリア」にあるボタン群で、プロジェクトの管理を行えます。

📄 HTMLエクスポート

作成したデザインと動作が全て含まれた、そのままWebサーバーで動く単体の .html ファイルをダウンロードします。

💾 セーブ / 📂 読み込み

現在編集中のデータをブラウザのローカルストレージに保存・復元します。作業の途中で中断したい場合に便利です。

⬇ JSON書き出し / 📥 インポート

プロジェクト構造をJSON形式で保存・読み込みできます。別のパソコンへデータを移動する際に使用します。

♻ リセット系機能

🗑 セーブリセット で保存データを削除、♻ プロジェクトリセット でキャンバスを初期化（白紙化）します。

8. 実践活用テクニック・FAQ

Q. 誤って削除してしまったり、ドラッグを失敗した場合は？

画面最上部の ↶ 戻る ボタンを押すと、一つ前の状態に復元できます（↷ やり直す で進めることも可能です）。

Q. プレビューを全画面でしっかり確認したい

プレビューエリア右上にある ⛶ (全画面表示) ボタンをクリックすると、ブラウザいっぱいに完成画面を表示して動作テストが行えます。

Q. スマホ対応（レスポンシブデザイン）にするには？

🎨 デザイン タブにある ↔ 横並び や ⊞ 2列グリッド を使用すると、画面幅に合わせて自動的に綺麗に折り返されるレイアウトが作れます。
